## ✨ Возможности

- 🎨 **Synthwave/Retro терминальный вайб** — цветной вывод постов с эстетикой 80х
- ⚡ **Быстрая навигация** — горячие клавиши и плавная пагинация
- 🔍 **Поиск и фильтры** — быстро найди нужный пост
- 💾 **Офлайн-кеширование** — читай посты без интернета
- 📱 **Адаптивный интерфейс** — работает на любом размере терминала
- 🎭 **Пасхалки и атмосфера** — функции которые приносят радость
- 🛡️ **Устойчивость к сбоям** — graceful degradation и умная обработка ошибок
- ⌨️ **Горячие клавиши** — быстрое управление из клавиатуры

## ⚙️ Требования

- **Node.js** >= 18.0.0
- **npm** >= 9.0.0
- Терминал с поддержкой цветов ANSI (Linux, macOS, Windows 10+)

## 🚀 Установка и запуск

### Быстрый старт (менее 1 минуты)

```bash
# Клонируем репозиторий
git clone https://github.com/ddd221/otets-cli
cd otets-cli

# Устанавливаем зависимости
npm install

# Запускаем приложение
npm start
```

### Конфигурация

Создай файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируй под свои нужды:

```env
API_BASE_URL=https://api.example.com
COLOR_THEME=synthwave
ENABLE_CACHE=true
```

### Развитие

```bash
# Запуск в режиме отладки с автоперезагрузкой
npm run dev

# Запуск тестов
npm test
```

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| `↑` / `k` | Прокрутка вверх |
| `↓` / `j` | Прокрутка вниз |
| `/` | Открыть поиск |
| `q` | Выход |
| `r` | Обновить |
| `h` | Справка |
| `→` / `l` | Следующая страница |
| `←` / `h` | Предыдущая страница |
| `1-9` | Переход на номер поста |

## 🏗️ Архитектура

### Слой API (`src/api/`)

- **`client.js`** — умный HTTP клиент с:
  - Автоматическими повторами (retry с exponential backoff)
  - Таймаутами
  - Обработкой сетевых ошибок
  - Graceful degradation

- **`endpoints.js`** — централизованное управление всеми API эндпоинтами

- **`cache.js`** — многоуровневое кеширование:
  - Памяти (в процессе)
  - Диска (для офлайна)
  - TTL для устаревания данных

### Слой UI (`src/ui/`)

- **`theme.js`** — система тем с поддержкой:
  - Synthwave (неоновые цвета)
  - Retro (классический терминал)
  - Dark mode (OLED friendly)

- **`renderer.js`** — рендеринг постов с:
  - Поддержкой markdown
  - Переносом текста
  - Форматированием

### Слой Utils (`src/utils/`)

- Парсинг и валидация данных
- Форматирование текста и дат
- Логирование и отладка
- Вспомогательные функции

## 🔍 Особенности реализации

### Обработка ошибок

Приложение включает graceful degradation:

```javascript
try {
  posts = await fetchLatestPosts();
} catch (error) {
  // Пытаемся использовать кеш
  posts = await cache.getFallback();
  showWarning('API unavailable, using cache');
}
```

### Retry логика

Exponential backoff для сетевых ошибок с максимум 3 попытками.

### Кеширование

Многоуровневое кеширование:
- В памяти процесса
- На диске для офлайн-доступа
- TTL для автоматического устаревания

Классический CRT-монитор вайб.
